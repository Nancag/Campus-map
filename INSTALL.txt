Campus map 校园拼车平台
=======================

安装与启动
----------

1. 确保已安装 Python 3.8+（无需 pip 安装任何依赖，纯标准库）

2. 解压本压缩包到任意目录

3. 打开终端（PowerShell / CMD），进入解压目录：

   cd campus_carpool

4. 启动服务器：

   python -m app.main

5. 浏览器打开：

   http://127.0.0.1:8000/map_amap.html    （拼车地图）
   http://127.0.0.1:8000/forum.html       （论坛）
   http://127.0.0.1:8000/                  （首页）

6. 让同局域网的人访问：

   http://你的IP:8000/map_amap.html

   （服务器默认绑定 0.0.0.0:8000，局域网内可直接访问）

停止服务器
----------

在终端按 Ctrl+C

目录结构
----------
  app/          后端代码（Python 标准库，无第三方依赖）
  static/       前端页面（HTML + CSS + JS + 高德地图）
  data/         配置文件（校区边界、校门坐标）
  scripts/      测试脚本
  tests/        单元测试
